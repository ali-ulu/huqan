# HUQAN Support

HUQAN uses different GitHub surfaces for different kinds of requests so bugs, design work, security reports, and general questions do not collapse into one queue.

## Use Issues for

- reproducible defects;
- bounded feature work;
- concrete documentation corrections;
- tracked engineering tasks.

Please use the repository issue forms when available.

## Use Discussions for

- installation and usage questions;
- design exploration before work is scoped;
- architecture questions;
- ideas that need community discussion before becoming an issue;
- showcasing integrations or experiments.

Discussions: https://github.com/ali-ulu/huqan/discussions

## Security vulnerabilities

Do **not** post exploit details, credentials, secrets, or sensitive evidence in a public issue.

Follow [SECURITY.md](./SECURITY.md) and use GitHub Private Vulnerability Reporting when it is available for this repository.

## What support does not imply

HUQAN is open-source software. A response, workaround, or roadmap discussion is not a warranty, SLA, or promise that a proposed capability will ship.

When documentation and live source disagree, live source and current tests win.
