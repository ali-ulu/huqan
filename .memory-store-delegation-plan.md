## Kanıtlanmış delegation pattern (PR #918 background-provenance)
1. Fonksiyon yeni modüle taşınır; `this` erişimi yerine açık parametreler alır (context object: { db, stmts, ... } veya ayrı parametreler)
2. Sınıf yöntemi artık tek satır: `return libFn(this, args...)` — delegation only
3. Test'ler pin-locked: "X sites call through delegate" — assert ile site sayısı sabitlenir
4. package.json files listesine modül eklenir
5. commit: refactor(arch-3): delegate ... (#328, ...) (#PRno)
